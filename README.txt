LANGKAH HARAPAN - PDF TO SCROLLABLE WEBSITE

1. Upload index.html and the complete assets folder to the root of your GitHub repository.
2. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
3. Select main branch, /(root), then Save.
4. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

Website reproduces each of the 8 PDF pages as images to preserve exact design/layout.
The Read More button on the first page links to the second page.
For accessible, searchable HTML content, text would need to be rebuilt as HTML, which may change precise typography.

Please verify that you have consent to publish the photos and details of minors before publishing publicly.
